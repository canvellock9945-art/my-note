7日間ルール (WebKit ITP 仕様):

SafariでWebサイトとして開いている際、7日間一度もアクセスしないと、ブラウザのキャッシュやIndexedDBが削除されるケースがあります。

対策: iPhoneで Safariの「共有メニュー」→**「ホーム画面に追加」**して起動するようにすれば、アプリ扱いとなり自律削除の対象から外れ、安全性が格段に高まります。

プライベートブラウズモード:

プライベートブラウズのタブでアプリを開いた場合、タブを閉じるとデータは全て消去されます。通常のブラウザタブまたは「ホーム画面に追加」した状態でご使用ください。

4.2 バックアップ機能の使い方（改訂版追加機能）

 保存 (JSON): ⚙️設定モーダルからクリックすると、全フォルダと全メモデータが入った .json ファイルをダウンロードできます。

 復元 (JSON): 保存した .json ファイルをアップロードすることで、いつでも端末へデータを完全復元・インポート可能です。
